# AI 프로덕트 매니저 학습 결과물 사이트

멀티캠퍼스 AI 프로덕트 매니저 과정에서 만든 기획 문서와 프로토타입을 주차별로 보여 주는 정적 웹사이트입니다. 빌드 과정이 없고, 목록 파일 하나로 화면이 만들어집니다.

## 구조

```
.
├── index.html         # 페이지
├── assets/            # style.css, app.js, thumbs/ (썸네일 이미지)
├── tools/make_thumbs.py  # 썸네일 자동 생성
├── tools/export_notes.py # 공개 노트 내보내기
├── data/works.json    # 프로젝트(결과물) 목록 (화면의 기준)
├── data/links.json    # 링크 모음
├── data/glossary.json # 용어
├── data/notes.json    # 공개한 노트 (비어 있으면 안내 화면)
└── works/             # 결과물 파일, 주차별 폴더
    ├── week-01/
    ├── week-02/
    └── week-03/
```

## 결과물 추가하기

1. 파일을 `works/week-0N/`에 넣습니다. 같은 결과물의 여러 버전 중 최신 하나만 넣습니다.
2. `data/works.json`의 `works` 배열에 항목을 추가합니다.

| 항목 | 설명 |
|---|---|
| id | 중복되지 않는 영문 식별자 |
| week | `week-01`, `week-02`, `week-03` 중 하나 |
| date | `YYYY-MM-DD` |
| title | 카드 제목 |
| type | 프로토타입, 기획 문서, 도식, 슬라이드, 보고서, 웹서비스 등. 종류 필터가 자동으로 생깁니다 |
| summary | 한두 문장 설명. 모르면 비워 둡니다 |
| file | 열어 볼 파일 경로. 파일이 없으면 비워 둡니다 |
| links | `{ "label": "서비스 열기", "url": "..." }` 목록 |

새 주차가 생기면 `weeks` 배열(start, end 날짜 포함)에도 추가합니다.

## 썸네일 만들기

Chrome이 설치된 맥에서 아래 명령을 실행하면 `works.json`의 모든 결과물 화면을 `assets/thumbs/아이디.jpg`로 만듭니다. 특정 결과물만 만들려면 아이디를 뒤에 붙입니다.

```bash
python3 tools/make_thumbs.py
```

항목에 `"thumb": "assets/thumbs/아이디.jpg"`를 적어야 카드에 표시됩니다.

## 노트 내보내기

비공개 노트 저장소에서 공개로 표시한 노트만 골라 이 사이트에 올립니다.

1. 공개할 노트의 앞부분(12줄 안)에 `공개: 예` 한 줄을 적습니다. 이 줄은 내보낼 때 지워집니다.
2. 아래 명령으로 먼저 미리보기를 합니다. 빠지는 구역과 줄이 모두 나옵니다.

```bash
python3 tools/export_notes.py ~/노트저장소경로 --dry-run
```

3. 결과를 확인한 뒤 `--dry-run`을 빼고 실행하면 `notes/`와 `data/notes.json`이 만들어집니다.

자동으로 빠지는 것: 교안, 슬랙, 회고, 출처, 메모, 과제, 링크 모음, 다음에 할 일 구역과, 교안이나 슬랙을 언급한 줄. 이메일, 전화번호, 키, 앱스 스크립트 주소 패턴이 남아 있으면 그 노트는 내보내지 않습니다. 공개 전에 결과 파일을 한 번 읽어 보세요.

## 내 컴퓨터에서 보기

`data/works.json`을 읽어 오기 때문에 파일을 직접 열지 말고 웹 서버로 엽니다.

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765`로 접속합니다.

## 올리기 전 점검

- 개인정보, 비밀 키, 외부 기관의 자료가 들어 있지 않은지 확인합니다.
- 파일명에 `내부`가 붙은 초안은 넣지 않습니다.
- 용량이 큰 파일(3MB 이상)은 꼭 필요한지 확인합니다.

## 배포

Vercel에서 이 저장소를 가져오면(import) 설정을 바꾸지 않고 바로 배포됩니다. 프레임워크는 Other, 빌드 명령과 출력 폴더는 비워 둡니다.
