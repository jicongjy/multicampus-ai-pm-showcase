프로젝트 지침과 안/밖 비교

  • 같은 질문을 프로젝트 안과 밖의 새 대화에서 던져 답을 비교하는 질문을 만들었습니다. 비교 항목은 파일명 형식, 가설 표기 여부, 화면 이름 사용 여부 세 가지입니다.
  • 비교 결과는 아직 정리하지 못했습니다.

컴퓨터 연결 실습

  • 컴퓨터와 연결이 끊긴 상태에서 바탕화면에 폴더 만들기를 요청하고, 웹 채팅과 데스크탑 앱에서 결과를 확인했습니다.
  • 연결이 없으면 폴더를 만들 수 없고, 대신 연결 방법을 안내해 줍니다.

올리브영 온라인몰 개선 제안서 (학습용 가정)

  • 검색해 보니 올리브영이 이미 앱에서 피부 진단을 출시한 것을 발견해서 문제 정의를 바꿨습니다.
  • 확정한 문제는 진단 결과가 검색 결과 화면과 상품 상세 화면에 이어지지 않아 처음 보는 상품을 고를 때 구매 확신을 얻기 어렵다는 것입니다.
  • 슬라이드는 요약, 시장 분석, 문제 정의, 해결 방안, 실행 계획의 다섯 챕터로 나누고, 페이지마다 어느 챕터인지와 무엇을 말하는지가 보이도록 고쳤습니다. IA 페이지와 와이어프레임 페이지도 따로 만들었습니다.
  • 구글 문서 PRD 템플릿 사본의 틀을 그대로 두고 문제 정의 파트 중심으로 간단히 채웠습니다. 데스크리서치 파트는 이번에 넘겼습니다.
  • PRD는 문제 60%, 설계 20%, 미정 20%로 배분하는 방식도 시도했습니다. 문제 파트에 힘을 싣고 설계는 방향만, 정해지지 않은 것은 표로 분리하는 방식입니다.
