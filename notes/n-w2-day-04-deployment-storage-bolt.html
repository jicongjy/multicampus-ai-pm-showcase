제가 만든 이벤트 신청 폼 실습 기록

수업 질문에 맞춰 제 신청 폼을 단계별로 고쳐 보았습니다.

단계바꾼 것
1에러 메시지를 빨간색으로 바꾸고, 오류가 난 입력칸 테두리도 빨간색으로 표시
2신청하기를 누르면 폼 화면이 사라지고 별도의 완료 화면 보여 주기
3처음에는 입력한 내용이 어디에도 저장되지 않는다는 것을 확인
4신청 내용을 브라우저에 임시 저장하고, 신청 명단 조회와 전체 삭제 버튼 추가
5휴대폰 번호를 필수로 변경
6중복 신청이 어떤 조건으로 판단되는지 코드로 확인

저장 방식에서 확인한 한계입니다.

  1. 신청 명단이 그 브라우저에만 있어서, 여러 사람이 신청하는 이벤트의 실제 접수 명단으로는 쓸 수 없습니다. 연습과 시연용입니다.
  2. 명단 버튼이 신청자에게도 보이면, 같은 컴퓨터를 쓰는 다음 사람이 앞 사람의 이름과 연락처를 볼 수 있습니다.
  3. 브라우저 데이터를 지우면 명단도 사라집니다.
  4. 입력규칙표(정의서)에는 휴대폰이 선택으로 적혀 있는데 폼에서는 필수로 바꿔서, 서로 맞춰야 합니다.

6. 오늘 느낀 점

  • 필드 정의를 더 체계적이고 상세하게 하는 방법을 배웠습니다.
  • 개발한 결과를 로컬에서만 확인해야 해서 팀에 공유하기 어려워 고민한 적이 많았는데, Netlify는 그럴 때 정말 좋은 도구인 것 같습니다.
  • 볼트는 처음 써 봤고, 개발과 데이터베이스, 배포까지 한 번에 되는 편한 올인원 도구인 것 같습니다.
  • 개발자 도구에서 저장값을 확인할 수 있다는 것도 처음 알았습니다.

7. 해 보고 싶은 것

신청 폼을 카카오톡 등에서 열리는 브라우저를 포함해 다양한 환경에서 점검해 보고 싶습니다. 다양한 노코드 도구와 배포 도구도 써 보려고 합니다.
