3-3. 로컬 테스트에서 겪은 문제

  • 증상: 구글 로그인 실패, Firebase: Error (auth/unauthorized-domain)
  • 원인: 로그인을 요청한 접속 주소가 파이어베이스의 허용 도메인 목록에 없을 때 발생합니다.
  • 해결 방향: 파이어베이스 콘솔의 Authentication, 설정, 승인된 도메인에 localhost를 추가하고, http://localhost:3000 주소로 접속해서 다시 시도합니다.
  • 배운 점: 로컬에서 테스트할 때는 파이어베이스에 허용 주소를 추가해야 합니다.
